# User Stories

## US01 - Task Management

**Description:** As an user of the application, I want to be able to create, update and delete tasks.

### US01 - Acceptance Tests

| Identifier | Scenario             | Description                       |
| ---------- | -------------------- | --------------------------------- |
| AT01.1     | Create a new task    | The user creates a new task       |
| AT01.2     | Update existing task | The user changes an existing task |
| AT01.3     | Delete existing task | The user deletes an existing task |

## US02 - Task View

**Description:** As an user of the application, I want to view all my tasks and filter them by status.

### US02 - Acceptance Tests

| Identifier | Scenario           | Description                                                     |
| ---------- | ------------------ | --------------------------------------------------------------- |
| AT02.1     | Show all the tasks | The user requests to view all the tasks saved                   |
| AT02.2     | Filter tasks       | The user requests to view svaed tasks and filter them by status |
