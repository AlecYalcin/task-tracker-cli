# Software Requirements Specification

## Functional Requirements

| Identifier | Title        | Description                                                  |
| ---------- | ------------ | ------------------------------------------------------------ |
| FR01       | Add Tasks    | Create new tasks with name and status                        |
| FR02       | Update Tasks | Change existing tasks name and/or status                     |
| FR03       | Delete Tasks | Remove existing tasks                                        |
| FR04       | List Tasks   | Show existing tasks and their status, filter tasks by status |

## Non-Functional Requirements

| Identifier | Title            | Description                                                                    |
| ---------- | ---------------- | ------------------------------------------------------------------------------ |
| NFR01      | Data Persistance | Tasks must be saved locally in a JSON File or SQLite database.                 |
| NFR02      | Usability        | Commands and help flags must be intuitive and follow stantard CLI conventions. |
| NFR03      | Compatibility    | The software must run smoothly on POSIX-compliant environments.                |
