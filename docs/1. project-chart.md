# Project Chart

## Description

Tracking tasts to be accomplished is a process that demands visual and logistical organization. To facilitate this activity, _task-tracker-cli_ was created, aiming to integrate task tracking into Linux terminals through easy-to-understand commands. It is designed for programmers and users accustomed to simple text interfaces, ensuring a concise and minimalist tracking experience.

This proposal does not include a graphical interface or web interface, being limited to Linux operating system terminals. There is no cloud synchronization support or a network-based user system, everything is done locally.
