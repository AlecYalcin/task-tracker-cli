# Project Chart

## Description

Acompanhar as tarefas a serem realizadas é um processo que damanda organização visual e logística. Para facilitar essa atividade, surge o _task-tracker-cli_, com o objetivo de integrar o acompanhamento de tarefas a terminais linux na forma de comandos fáceis de se entender. Ele serve para programadores e usuários acostumados com interfaces de texto simples, garantindo um acompanhamento conciso e minimalista.

Essa proposta não inclui interface gráfica ou interface web, se limitando aos terminais de sistemas operacionais linux. Não há suporte de sincronização em nuvem nem um sistema de usuários por rede, sendo feito tudo localmente.
